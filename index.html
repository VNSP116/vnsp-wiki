Вход для администратора

Правила

  • Не грифь, не воруй и не вреди другим игрокам намеренно.
  • Читы и софт, запрещённые на любом сервере, использовать нельзя.
  • PVP только по согласию. Звать на дуэль и устраивать договорные бои и испытания можно.
  • Сервер закрыт вайтлистом, чтобы незваные гости не могли ему навредить.

Что за нарушения

За любое нарушение устава можно получить бан. Если игрока забанят за гриферство, админы восстановят пострадавшие постройки.

Гайд

Нажми на команду, чтобы скопировать её.

Об игре

  • Сложная сложность: выживать придётся по-настоящему.
  • Профиль и рейтинг показывают, сколько ты сделал для сервера.

Профиль и рейтинг

Система профилей и рейтинга по всей статистике игрока и достижениям на сервере. Она может показать насколько игрок много сделал для этого сервера.

/profile (player)Открыть свой профиль или профиль другого игрока
/topТоп игроков по уровню
/pdesk (clear)Изменить описание профиля или очистить его

Поселения

Каждый игрок может состоять только в одном поселении: создать своё или вступить в чужое по приглашению.

/sel (list, open)Открыть список поселений: от самого большого к самому маленькому
/sel helpСправка по командам. Любая неизвестная подкоманда тоже открывает её
/sel create (название)Создать поселение. Название 3–20 символов: буквы, цифры, пробел, _ и -. Состоять можно только в одном поселении
/sel info (название)Открыть состав поселения. Без названия покажет твоё
/sel acceptПринять приглашение. Оно действует 60 секунд
/sel denyОтклонить приглашение
/sel leaveВыйти из поселения. Глава выйти не может, только удалить поселение
/sel title (текст)Задать себе должность, до 24 символов
/sel title clearУбрать свою должность

Только для главы поселения

/sel deleteПредупредить об удалении и попросить подтверждение
/sel delete confirmУдалить своё поселение. После этого можно создать новое
/sel invite (player) (должность)Пригласить игрока, который сейчас в сети. В поселении максимум 36 игроков. Должность необязательна
/sel kick (player)Исключить игрока из поселения
/sel icon (#блок)Сменить иконку поселения, например /sel icon #dirt или /sel icon #minecraft:diamond
/sel desc (текст)Задать описание, до 120 символов. Необязательно
/sel desc clearУбрать описание
/sel coords setЗаписать координаты и мир, где ты стоишь. Необязательно
/sel coords clearУбрать координаты

Кастомизация игрока

Пару команд, которые могут добавить немного кастомизации: поменять возле ника префикс на абсолютно любой, скин можно сменить на тот, который использует лицензионный игрок. (на сайте ниже можно найти нужный скин и ник для команды).

/skin set (player)Поставить скин любого игрока
/prefix (слово)Добавить приписку к нику. Для цвета используй код, например &1Слово. Эмодзи из игры тоже работают
